# gpui-fast-web

GPUI with gpui-fast rendering and layout optimizations.

Source and documentation: [https://github.com/NtTestAlert/gpui-fast](https://github.com/NtTestAlert/gpui-fast).

Forked from Zed's GPUI; distributed under Apache-2.0.

Use the core as `gpui = { package = "gpui-fast", git = "https://github.com/NtTestAlert/gpui-fast", branch = "atrophy-dist-0.1.12" }` to preserve paths emitted by its macros.
